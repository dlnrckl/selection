# Selection

This repository contains analysis scripts developed as part of an ongoing, unpublished study investigating genetic variation and evolutionary patterns in Anatolia over the last 10,000 years.

The repository includes code for:

- allele-frequency calculations,
- population-genetic summary statistics,
- neutral simulations implemented in SLiM.

The allele-frequency and summary-statistics analyses correspond to work presented in the manuscript section:

**“Phenotype-associated allele frequencies depart from neutral expectations across 10,000 years in Anatolia and reveal heterogeneous evolutionary signatures.”**

The SLiM-based neutral simulations are included as additional analysis code developed during the project, but were not included in the current manuscript.

Additional documentation is provided within the relevant subdirectories.
